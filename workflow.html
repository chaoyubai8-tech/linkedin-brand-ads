广告制作工作流

从「给谁看」到「交付什么」，把每一步的素材、Skills、工具和验收标准放在一起。

Skills 提供规则，AI 按规则执行，工具完成制作，审稿决定是否通过。这不是一键生图，也不是运行一个 skill 就自动完成整套广告。

制作必须经过素材中台

确认人群与规范 → 中台选材预检 → 中台 Skill Agent／工作流制作 → 必要渲染与逐项验收 → 版式精修 → 成稿复验、回存与审稿发布。

这是本项目已确认的执行要求。素材中台负责选材与制作留痕，不只是备用图库；本地 Skills 负责指导和检查，Blender 与排版工具负责必要精修，GitHub 负责展示。三者不能互相替代。

04

进入素材中台制作，保留执行记录

真实模型与概念图都先进入中台制作链路；不能因为本地工具方便就跳过中台。

执行位置中台 Skill Agent · 历史会话tripo-ad-workbench · 本地指导tripo-model-showcase · 本地验收
  1. 把已确认的任务带入中台。写明广告编号、人群、主利益、选定素材、尺寸和规范要求；明确真实模型展示还是概念图，沿用四组方向和暂停 Before / After 的决定。
  2. 查看并选择中台实际可用的 Skill／工作流。核对输入、输出类型和所用模型／工具；需要生成时确认授权和消耗。提交后先查询状态，不在返回不明时重复运行。
  3. 保留输入到结果的对应关系。记录素材条目、会话／任务、实际工作流名称、输入版本、输出文件与运行结果；有结果还要打开看图，不能只看“完成”。
  4. 制作检查图，逐项验收后再排版。需要真实多视角时，用 Blender 生成检查图，按规范验收主体，再交给 HTML/CSS 等工具精修版式；把外部处理及最终版本关联回制作记录。
  5. 回存并复核。将获准保存的成稿和版本说明回存对应中台位置，重新打开条目核对文件、版本及来源关系；只看到保存弹窗关闭，不算回存验证完成。

这里规定的是本项目制作流程，不声称中台自动完成每项检查、自动同步所有文件，或保证包含某个特定模型。应先核对当前可用工作流；历史会话不能充当本次已运行的证据。
