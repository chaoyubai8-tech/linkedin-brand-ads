制作与核验：2026-10-08。四张均为 **1440 × 1440 PNG + 可编辑文字 SVG**，尚未批准投放，未操作广告账户。本轮不是 Figma 同步稿。

| 广告 | 对象与主张 | 视觉与证据 | 结论 |
| --- | --- | --- | --- |
| T15-01 | 游戏团队负责人：One team. One asset library. | 中台自有角色原图衍生的 GPT 概念图，配共享资产与 Artist / Developer 关系 | 团队价值清楚；AI concept artwork / Workspace concept 已标，不是产品 UI 或实时共编证据 |

结论：沿用大字、简洁品牌配色，改用可追溯的自有中台素材；Teams 用概念美术建立角色吸引力，API 用真实几何说明工作对象。不同证据不混称。

## 素材链路与边界

- Teams：自有素材目录中的原始部落机器人输入 → 中台 AI 作图 GPT Image 2.5 Flare 的无字主视觉 → 官方 Logo 和 Instrument Sans 原生排版。彩色图是二维概念重绘，不能称为现有 FBX 的贴图渲染。
- API：同目录原始输入与对应 FBX → Blender 独立场景统一朝向、哑白材质与前侧塑形光 → 白模及真实 mesh.edges 黑线框。未修改几何、补纹理或重拓扑。
- 真实网格含 24,666 多边形、40,714 三角形；没有 UV / 贴图，存在背部缝隙与不均匀布边。选定主视角可作静态几何说明，不等于完整生产验收。上述技术统计不在广告图中作营销承诺。
- 既有库素材的生成引擎版本未由回执确认，因此不宣称最新引擎或本次重新生成；库内分组标签不作为引擎版本。
- 素材中台 vast-three-view v2.1 已试跑三图，但请求的自身左视图左右细节不一致，整套不通过准确三视图验收。**三张试跑图未用于这四张广告。**
- 没有本次 API 请求、生成时长、绑定、引擎运行或效果投放数据；不写速度、8K、倍数、无需清理、game-ready 或 CTR 提升。

结论：V15 完成的是可审核的广告版式及素材证据说明，不是新一轮模型算法对比或生产就绪认证。

## 承诺与官方依据

核验日期均为 2026-10-08。

- 共享资产库、共享积分、管理员席位/权限/用量：[Team Program](https://www.tripo3d.ai/programs/team-program)、[Team Plan](https://www.tripo3d.ai/blog/tripo-turns-1-team-plan)。可见范围受管理员设置影响；不是 Teams 与 API 共享积分。
- API集成与异步任务：[API Introduction](https://developers.tripo3d.ai/en/docs/introduction)、[Task Query](https://developers.tripo3d.ai/en/docs/task-query)。提交后查询任务，成功后取回输出，不保证任务必然成功或即时完成。
