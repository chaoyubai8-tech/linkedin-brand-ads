See the workflow, or leave your details to discuss a team trial. Tripo will follow up about your team's needs and trial availability.
你好，我们是 Tripo。

还在请同事重复发送同一个角色或道具文件吗？

Tripo Studio 团队版提供共享工作区，让游戏团队创建并整理角色与道具模型。授权成员可以查找并复用这些资产，减少重复索要和交接文件的操作。

回复 1 / Response 1

Create character and prop models in the team workspace, then organize them in the library. Authorized teammates can find shared models and reuse them for another task.

Keep review and refinement in the tools your team already uses. The shared workspace supports asset handoffs; it does not replace project-specific quality checks.
在团队工作区创建角色与道具模型，再集中整理到资产库中。授权成员可以找到共享模型，并在后续任务中复用。

Your team checks and refines the assets, then tests their use in the project with its existing tools. This is an example workflow, not a claim about a completed customer game.
从游戏项目需要的角色与道具出发，创建初始模型并整理到团队资产库，方便授权成员查找。

主题 / Subject Can 3D generation fit your asset workflow?

开场 / Opening

Hi, I’m with Tripo.

Still moving between 3D generation and your game or asset tools?

Tripo API lets your tool submit a generation task, check its status and retrieve the model after success. Your team builds the integration, then reviews and develops the result in its existing game or asset tools.

See the workflow, or open the Quick Start.
你好，我来自 Tripo。

还在 3D 生成与游戏或资产工具之间来回切换吗？

Tripo API 让自有工具提交生成任务、查询状态，并在成功后取回模型。由团队实现工具接入，再在已有的游戏或资产工具中检查并完善结果。

可以先了解工作流程，也可以打开 Quick Start。

  • Plan a first request · 规划首次请求 → 回复 2

回复 1 / Response 1

Your tool submits a generation request and receives a task ID. Track the task's status and retrieve the model after success.

Connect the result to your existing asset review and refinement steps. Your team builds the integration and checks the model for its intended game or asset workflow; a successful task is not production approval.
你的工具提交生成请求并收到任务 ID，跟踪任务状态，在成功后取回模型。

再将结果衔接到已有的资产审核和完善步骤。接入由团队实现，模型也需按实际游戏或资产流程检查；任务成功不等于通过生产验收。
  • Open Quick Start · 打开 Quick Start → API Quick Start

回复 2 / Response 2

Choose one asset request and define where its result should enter your tool or asset workflow. Test submission, status handling and retrieval, including what happens if a task fails.

Then inspect the model against your project's requirements before using it. The Quick Start provides request and response examples for this first integration check.
选择一项资产请求，明确结果应进入工具或资产流程的哪个环节。测试提交、状态处理和结果取回，包括任务失败时的处理。

随后按项目要求检查模型，再用于后续工作。Quick Start 提供请求与响应示例，便于验证首次接入。
