# Tripo 站内信工作室

独立于历史稿的 Conversation Ads 审阅子站。四组已确认人群，各有三个任务切入，共十二套创意候选；英文文案与完整中文释义同步。不是广告后台，不会发送消息或提交表单。

## 使用

从已有项目根目录启动静态 HTTP 服务，再打开 `messaging-lab/index.html`。不要只双击文件：交互需要读取同目录 JSON。无需安装依赖或构建。

- `index.html`、`lab.css`、`lab.js`：原生静态前端。
- `copy.json`：十二套候选、三十六条预设消息及按钮出口。
- `research.json`：人群、参考案例、来源和逐项核查状态。
- `all-copy.html`：不依赖脚本的完整双语文字。
- `copy.csv`：带 BOM 的 UTF-8 文案表；只含主题、正文、按钮与补充说明，不含内部创作理由。

## 审稿逻辑

人群 → 本组任务切入 → 对话预览／路径与全文／写作理由／品牌与上线核对。

分支仅为预设消息；网站按钮先展示目的地，再由审稿人手动打开。Not Interested 是平台系统选项说明，不算自定义按钮，也不导出到文案字段。

十二套是供选稿的概念候选，不是十二个新增定向。本轮建议先选每组一个母版，再各做两个开场版本，共八个；这是新方向下的测试建议，不是旧策略已确认的数量，也未新增预算。再营销和 Before / After 未恢复。整条概念一起改不应被称为只改变单一变量的 A/B。

## 验收边界（2026-10-11）

Studio Context 与视觉规范文字已读；品牌语言仅部分章节已读；L1 合规正文未完整读取。未完成全部品牌与合规验收。

发送者授权、实际可投地区与语言、原生 Lead Gen Form、配图、事件承接和 Campaign Manager 预览均需另行验收。配图制作须使用素材中台并核对真实来源和模型证据。当前网站不是已批准上线的广告。

页面不转载内部手册全文、原始案例 PDF、联系人、私有价格表或凭证。对案例只借鉴路径，历史案例表现不是 Tripo 成效证明。代码公开可审阅；品牌、第三方内容与素材权利不因源码公开而被重新授权。

“品牌与上线核对”包含按产品过滤的承诺台账：出处、2026-10-11 核验日期、条件与禁用推论。它不替代品牌手册全文、L1 合规或实际账户验收。
